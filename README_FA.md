# فاکتور ساز شخصی

پروژهٔ اندروید با رابط فارسی و راست‌به‌چپ. امکانات نسخهٔ اولیه:
- ثبت فاکتور با نام مشتری، تلفن، شرح کالا/خدمات، تعداد، قیمت واحد و تخفیف
- محاسبهٔ مبلغ نهایی
- ذخیره، فهرست و حذف فاکتورهای محلی با SQLite
- تولید فایل PDF و اشتراک‌گذاری آن

## ساخت APK
در GitHub مخزن را با حفظ ساختار پوشه‌ها بارگذاری کنید. سپس از Actions، گردش‌کار `Build Invoice Maker APK` را با `Run workflow` اجرا کنید. فایل خروجی در Artifact با نام `InvoiceMaker-APK` قرار می‌گیرد.

این نسخهٔ اولیه است؛ مدیریت چند قلم کالا در یک فاکتور، اطلاعات ثابت فروشنده/لوگو، شماره‌گذاری حرفه‌ای، پشتیبان‌گیری و OCR هنوز پیاده‌سازی نشده‌اند.
